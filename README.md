# first_project_on_c++
відповіді на запитання
0 Роль компоновника (linker)
Компоновник збирає єдину програму з окремих файлов. Він обєднує розрізнені файли скомпільованого коду, та підключає зовнішні бібліотеки
1 Відмінність об’єктного файлу від виконуваного
Об’єктний файл це необроблений машинний код одного модуля. У ньому відсутні адреси, тому запустити його безпосередньо неможливо
Виконуваний файл це готовий кінцевий продукт. Усі зв’язки в ньому налаштовані, і операційна система може одразу його виконати
2 Функція директиви #include <iostream>
Ця команда наказує препроцесору вставити вміст заголовного файлу iostream у ваш код. Завдяки цьому програма дізнається, як використовувати об’єкти вводу-виводу std::cout і std::cin
3 Чому C++ це мова високого рівня
C++ використовує зрозумілі людині терміни (if, for) замість складних машинних інструкцій процесора (наприклад ассемблер). Написаний код є універсальним, що дозволяє компілювати його під різні операційні системи без зміни логіки.
